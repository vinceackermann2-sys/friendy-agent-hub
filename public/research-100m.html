Model cards · 100M programme

TAM v3 · Cortex-S · 12 min read

Can a hybrid beat the Transformer?

Two alternatives that carry a running memory alongside attention, each trained at 100 million parameters on 2 billion tokens, raced against an identical Transformer. Same card structure for both models — specs, architecture, results, take — then one folder you can download.

100M parameters 2B tokens H100 · bfloat16 One download folder
TAM v3Cortex-SProtocolDownload

At a glance

  • Both hybrids beat a matched Transformer on loss and perplexity at 25M, 50M and 100M.
  • Predicting text is not the whole story: the Transformer is about a third faster and still wins most quiz benches.
  • Replicate from one folder — data, TAM, Transformer, Cortex-S, compare. No inline dump.

TAM v3

Temporal Associative Memory: reduced-width causal attention and a diagonal affine scan run in parallel. A learned gate mixes them.

4

Take

Real signal, not a breakthrough

The recurrent state helps language modelling. It does not yet buy wall-clock or quiz wins.

  • +Lower loss at every scale we tested.
  • +Significant memory edge at 256 tokens.
  • −Transformer is ~⅓ faster and wins 4 of 5 quizzes.
  • −No broad long-context win past 512.

Next: TAM v4 (cross-chunk state, novelty write gate) at small scale before more GPU budget. Scaling v3 past 100M is not justified on these numbers.

Model card 02

Cortex-S

Sparse mixture-of-experts with persistent recurrent state. Full attention only every sixth layer — the rest ride the state. A second, independent design on the same frozen 2B-token corpus.

101.8M params 8 experts · top-2 Safety-bounded state
1

Specs

Parameters
101,778,112
Experts
8 feed-forward, top-2 routing
Attention
Full causal only when layer_id % 6 == 0
State
128 values per layer, tanh-bounded write
Safety
Deterministic kernel bound on every step
Protocol
Same data, seed, hardware as TAM / Transformer
2

Architecture

State write is tanh-bounded, so every step stays in a fixed range and is auditable by construction.

Take

Not a fluke of one design

A completely separate architecture, same frozen corpus — and it also beats the Transformer on loss. The hybrid signal is real. The compute and quiz caveats from TAM still apply.
