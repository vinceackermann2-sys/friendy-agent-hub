Semantic structure and explicit memory at small scale

STLM and Mini-SLA compared with a Transformer baseline on language modelling, meaning alignment and targeted negation probes.

Small-scale programme · STLM · Mini-SLA · The Belna team

This programme tests two ways to encode structure in small language models. STLM adds supervised semantic axes to a Transformer core. Mini-SLA adds shared recurrent computation, explicit entity memory and a negation router.

Both are evaluated against a Transformer baseline on the reported WikiText-2 and templated-state mixture. The main outcomes are test perplexity, next-token accuracy, meaning correlation and two small targeted probe suites.

STLM reaches 35/35 on the negation probe only with an inference constraint. Mini-SLA reaches 35/35 without one; neither result establishes general reasoning beyond this probe.

Model card 01

STLM

Research question. Can explicit semantic axes improve next-token prediction and distinguish antonyms in a small language model?

Architecture

Semantic Topology Language Model uses a Transformer core with a topology classifier, coordinate regressor and axis embedding. Its joint objective combines language-model loss with topology classification and seed-coordinate supervision, encouraging selected antonyms to occupy opposite ends of an axis.

Results

Plain test perplexity is 80.89 versus 111.45 for the baseline; Pearson correlation on 30 meaning pairs is 0.957 versus −0.069. The 35-item negation probe is solved only with an inference-time constraint.

Interpretation and limitations

Auxiliary semantic supervision improves the reported correlation and plain perplexity, but the plain model solves 0/35 negation probes. The 35/35 result requires an inference-time bias, while grammar agreement is 40/50 versus 46/50 for the baseline. The 30-pair correlation and 35-item negation sets are narrow probes.

Model card 02

Mini-SLA

Research question. Can an explicit memory and negation router solve the same probes without an inference-time constraint?

Architecture

Mini-SLA applies one Transformer layer four times with shared weights. It reads and writes a ten-slot key-value entity memory. A symbolic router blends a memory read with its negated value when the negation path fires, so this probe does not require an inference-time constraint.

Interpretation and limitations

Mini-SLA solves all 35 templated negation items without an inference constraint, but grammar agreement is 41/50 versus 46/50 for the baseline and training takes longer. The narrow probe cannot establish broad reasoning ability or predict behaviour at 100M parameters.

Shared protocol

The reported comparison uses seed 42, an 85/5/10 train/validation/test split and the same probes. STLM also changes the training objective through its auxiliary supervision; Mini-SLA uses language-model loss alone. Perplexity is the exponential of mean token negative log-likelihood, so lower is better.
