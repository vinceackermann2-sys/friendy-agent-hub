Can a hybrid beat the Transformer?

Two 100M designs with a running memory, raced on the same 2B tokens.

100M programme · TAM v3 · Cortex-S · The Belna team

The Transformer is the default because it is simple, fast, and good at quizzes. We asked a narrower question: if you give a model a running memory alongside attention, does the loss actually move?

Two answers, same protocol. Each model is about 100 million parameters, trained on 2 billion tokens, against an identical Transformer. Same data mix. Same seed. Same H100. If the hybrid signal is real, it should show up twice.

Both hybrids beat a matched Transformer on loss. Predicting text is not the whole story — the Transformer is still about a third faster, and it still wins most quizzes.

Model card 01

TAM v3

Temporal Associative Memory: reduced-width causal attention and a diagonal affine scan run in parallel. A learned gate mixes them. About 55% of the signal goes through state.

Specs

Parameters
101,806,616 (Transformer: 101,803,520)
Block
Attention ∥ diagonal affine scan, gated mix
Mix
out = 2 × ((1−g)·attn + g·state)
Data
2B tokens, identical mix and seed 8100
Context
512 · GPT-2 tokenizer
Hardware
H100 · bfloat16 · torch.compile · AdamW

output = 2 × ((1 − g) × attention + g × world_state)

Lower loss at every scale we tested. Not a faster model. Not a better quiz-taker.

At 256 tokens, state tracking was +11.5 pp and needle retrieval +12.5 pp. The edge fades where full attention already holds the dependency.

Real signal, not a breakthrough

The recurrent state helps language modelling. It does not yet buy wall-clock or quiz wins.

  • +Lower loss at every scale we tested.
  • +Significant memory edge at 256 tokens.
  • −Transformer is ~⅓ faster and wins 4 of 5 quizzes.
  • −No broad long-context win past 512.

Next: TAM v4 (cross-chunk state, novelty write gate) at small scale before more GPU budget. Scaling v3 past 100M is not justified on these numbers.

Model card 02

Cortex-S

One design can be a fluke. Cortex-S is a completely separate architecture on the same frozen 2B-token corpus: sparse mixture-of-experts, persistent recurrent state, full attention only every sixth layer. The rest ride the state. The write is tanh-bounded, so every step stays in a fixed range and is auditable by construction.

Specs

Parameters
101,778,112
Experts

Attention
Full causal only when layer_id % 6 == 0
State
128 values per layer, tanh-bounded write
Safety
Deterministic kernel bound on every step

Same data, seed, hardware as TAM / Transformer

Not a fluke of one design

A completely separate architecture, same frozen corpus — and it also beats the Transformer on loss. The hybrid signal is real. The compute and quiz caveats from TAM still apply.

Shared protocol

One race, three runners. Nothing below is free to drift between TAM, Cortex-S, and the Transformer.

2B

Tokens — FineWeb-Edu 45%, FineMath 17.5%, StackV2 15%, Cosmopedia 15%, ArXiv 7.5%

8100

Same seed — AdamW, cosine 3e-4, wd 0.1, clip 1.0, effective batch 128

H100

Hardware — bfloat16, micro 64 × accum 2, context 512

SFT+DPO

Post-train — SmolSmolTalk 100K, then UltraFeedback 10K pairs
