## Reproduce

1. Run `npm run build` and `npm run preview`.
2. Set `UI_BASE` to the preview URL, then run `npm run test:ui`.
3. Set `UI_SCREENSHOTS=1` when running `scripts/ui-audit.mjs` to save mobile screenshots under `test-results/`.
